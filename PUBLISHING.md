# Publicação pública da V3

Repositório: https://github.com/Arielcs/code-performance-analyzer

Este repositório contém exclusivamente a skill Code Performance Analyzer V3, suas referências genéricas, scripts de apoio e testes sintéticos. Não inclui fontes, credenciais, métricas, relatórios nem dados de projetos particulares analisados.

## Instalação

Use o diretório raiz do repositório como diretório da skill, pois `SKILL.md` está na raiz. Para executar os testes: `python3 -m unittest discover -s tests -v`. Instruções adicionais em `README.md`.

## Privacidade

A publicação deste repositório público não altera visibilidade nem permissões dos demais repositórios privados da conta GitHub. Mantenha resultados de análises de código confidencial fora deste repositório.
